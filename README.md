A deadpan one-star review, in a single line of 160 characters or fewer, of an everyday essential everyone relies on: sleep. It files the complaint in earnest — eight hours a night, still waking up tired — and the sting lands in the last few words.

## Run it

```sh
python3 main.py
```

This writes the review to `/output/entry.txt`.
